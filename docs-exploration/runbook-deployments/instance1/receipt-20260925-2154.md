## Deviations from the Runbook

1. **NVIDIA DRA Helm Chart Options (Attempt 1 & 2):**
   - *Why:* The upstream `nvidia-dra-driver-gpu` v25.8.0 chart requires explicit override flags (`resources.gpus.enabled=true` and `gpuResourcesEnabledOverride=true`) to register physical GPU device classes. Additionally, GKE standard namespace quotas reject `system-node-critical` priority classes, default controller affinity targets non-existent control plane nodes, and the kubelet daemonset requires tolerations for `nvidia.com/gpu=present:NoSchedule`.

## Recommended Runbook Changes

```bash
# Install NVIDIA DRA GPU driver via Helm
helm repo add nvidia https://helm.ngc.nvidia.com/nvidia
helm repo update
helm install nvidia-dra-driver-gpu nvidia/nvidia-dra-driver-gpu \
  --version="25.8.0" \
  --create-namespace \
  --namespace nvidia-dra-driver-gpu \
  --set nvidiaDriverRoot="/home/kubernetes/bin/nvidia/" \
  --set resources.gpus.enabled=true \
  --set gpuResourcesEnabledOverride=true \
  --set controller.priorityClassName="" \
  --set kubeletPlugin.priorityClassName="" \
  --set controller.affinity=null \
  --set-json 'kubeletPlugin.tolerations=[{"key":"nvidia.com/gpu","operator":"Exists","effect":"NoSchedule"}]'
```
